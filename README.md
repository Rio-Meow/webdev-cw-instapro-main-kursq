# Instapro

MVP социальной сети для обмена фотографиями

Приложение позволяет просматривать ленту постов с именами авторов, аватарами и описаниями, ставить лайки авторизованным пользователям и переходить на страницы пользователей для просмотра их постов. Пользователи могут регистрироваться и входить в систему.Приложение также может позволять создавать новые посты. Приложение разработано с использованием JavaScript, HTML и CSS.
